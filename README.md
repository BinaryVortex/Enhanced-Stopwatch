# Enhanced Stopwatch

A simple yet enhanced stopwatch web application built using HTML, CSS, and JavaScript. This stopwatch features a clean UI, audio feedback, and a progress bar that visualizes the passage of time.

## Features

- **Start/Stop Functionality**: Easily start and stop the timer with a single button.
- **Reset**: Reset the timer back to 00:00:00.
- **Time Display**: Displays time in HH:MM:SS format with leading zeros.
- **Progress Bar**: A visual progress bar that fills every minute (resets every 60 seconds).
- **Audio Feedback**: Sound effects play on start, stop, and reset actions.
- **Responsive Design**: Clean and modern UI that works on various screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Use

1. Clone the repository:
   ```
   git clone https://github.com/BinaryVortex/Enhanced-Stopwatch.git
   ```

2. Open `index.html` in your web browser.

3. Click the "Start" button to begin timing.

4. Click "Stop" to pause the timer.

5. Click "Reset" to reset the timer to zero.
